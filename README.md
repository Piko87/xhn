# 席衡 · 剧场演出工作台

一期只覆盖「剧场演出」。本地 SQLite，首次启动自动写入演示剧目、场次、库存和订单。不连接外部票务系统。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:3000 。业务时间按 Asia/Shanghai 计算。

重置演示库：

```bash
npm run db:reset
```

然后重启开发服务。数据库文件在 `data/xhn.sqlite`，不提交。

## 演示剧目

《江城夜航》在江城大剧院 · 镜厅，分区为池座、楼座、侧厢。企业团购在池座和侧厢持有独立库存，其余渠道共用共享池。11 月 15 日晚场共享池偏紧，侧厢独立库存已占满。《灯河》在实验小剧场，库存对客实时显示。

姓名、手机、证件号、订单号和价格都是虚构的。

## 本期不做

短信和微信不会真的发出，重发只记一笔。没有支付网关。没有景区、套票、旅游券、资源中心、财务、大麦或猫眼对接。没有按渠道定时放票，也没有订单改场次。独立库存按数量占用，不预绑到具体座位。退货审核页只保留入口说明。
